## Problem Set 1

`ps1/code/PS1_complete_solution.m`

### Supporting function

`ps1/code/arma_generator_ps1.m`

### Outputs

Running the main script generates the relevant tables, figures, and MATLAB result files in:

`ps1/outputs/`

The script uses paths relative to its own location, so it should run after cloning the repository without requiring user-specific absolute paths.

## How to run PS1

1. Clone or download this repository.
2. Open MATLAB.
3. Open `ps1/code/PS1_complete_solution.m`.
4. Run the script.
5. Generated outputs will be saved automatically in `ps1/outputs/`.

## Collaboration workflow

The `main` branch contains the current accepted version of the project.

For proposed changes:

1. Create a new branch.
2. Make and test the changes on that branch.
3. Commit and push the changes.
4. Open a Pull Request into `main`.
5. Review and discuss the proposed changes before merging.

This workflow allows group members to suggest modifications without directly replacing the accepted version of the code.
